# Asset provenance and rights

## Generated runtime pack

The PNG runtime pack is generated deterministically by `ProjectTools/AssetGeneration/generate_visual_assets.py`. It uses original geometry and a limited comic-game palette. No pixels from the downloaded reference files were copied.

The WAV files were created through LS-CLAD's local algorithmic synthesis:

- no audio samples
- no training datasets
- no Unity AI credits
- no Lens Studio runtime dependency

The generated files are ordinary PNG, GIF-preview, JSON, Markdown, and WAV assets.
